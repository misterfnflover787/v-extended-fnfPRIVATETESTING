This page tracks the release history of V-Extended and V-Extended Mobile. Both variants are developed independently by MFF Studio and may be at different version numbers at any given time. Check the section for your platform below.

<Note>
  For the most up-to-date release notes, check the V-Extended releases page on the project repository.
</Note>

## V-Extended (PC)

<Note>
  **Current version: v1.4.5** — Polymod API compatibility: **0.8.0**
</Note>

### v1.4.5 <span style={{color: '#16a34a', fontSize: '0.85em'}}>(Latest)</span>

**v1.4.5** is the current release of V-Extended for PC. This version includes the following features accessible from the V-Extended page in the FNF Options menu:

| Feature | Description |
|---|---|
| **Ghost Tapping** | Prevents misses when pressing note keys with no notes present. |
| **Options in Pause** | Adds a shortcut to the V-Extended options page from the pause menu. Disabled by default. |
| **Botplay in Pause** | Allows toggling Botplay from the pause menu. Restarting the song is required. Disabled by default. |
| **Middlescroll** | Centers the player's strumline in the middle of the screen. |
| **Opponent Notes Opacity** | Controls the visibility of the opponent's note lane. |
| **Strumline Background** | Toggles a background behind the strumline. |
| **Strumline Background Opacity** | Adjusts the transparency of the strumline background. |
| **Strumline Background Padding** | Controls the padding around the strumline background. |
| **Time Bar suite** | A collection of settings for the song progress bar display. |
| **Detailed Score Counter suite** | A collection of settings for the in-game score and judgment display. |

<Note>
  A full detailed changelog for v1.4.5 and prior releases will be published on the V-Extended releases page in the project repository.
</Note>

## V-Extended Mobile

<Note>
  **Current version: v1.2.1** — Polymod API compatibility: **0.8.0**
</Note>

### v1.2.1 <span style={{color: '#16a34a', fontSize: '0.85em'}}>(Latest)</span>

**v1.2.1** is the current release of V-Extended Mobile. This version includes the following features accessible from the V-Extended page in the FNF Options menu:

| Feature | Description |
|---|---|
| **Alternative Note Input** | Provides an alternative control scheme for mobile note input. Requires restarting the current song to take effect. |
| **Options in Pause** | Adds a shortcut to the V-Extended options page from the pause menu. Disabled by default. |
| **Botplay in Pause** | Allows toggling Botplay from the pause menu. Restarting the song is required. Disabled by default. |
| **Opponent Notes Opacity** | Controls the visibility of the opponent's note lane. |
| **Strumline Background** | Toggles a background behind the strumline. |
| **Strumline Background Opacity** | Adjusts the transparency of the strumline background. |
| **Time Bar suite** | A collection of settings for the song progress bar display. |
| **Detailed Score Counter suite** | A collection of settings for the in-game score and judgment display. |
| **Mobile Pause Menu Auto-Layout** | Automatically adjusts the pause menu layout to prevent items from overlapping on mobile screens. |

<Note>
  A full detailed changelog for v1.2.1 and prior releases will be published on the V-Extended releases page in the project repository.
</Note>
