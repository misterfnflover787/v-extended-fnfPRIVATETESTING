By default, Friday Night Funkin's pause screen only lets you resume, restart, or exit. V-Extended can inject two extra entries — an Options shortcut and a Botplay toggle — right into that menu, letting you tweak settings or flip Botplay on the fly without ever leaving your current song session.

<ParamField body="Options in Pause Menu" type="boolean" default="false">
  Adds an **Options** entry to the pause menu. Selecting it navigates you to the full Options screen so you can adjust any setting mid-session. When you exit Options, the current song automatically reloads so your changes take effect immediately.
</ParamField>

<ParamField body="Botplay in Pause" type="boolean" default="false">
  Adds a pause-menu button that restarts the current song with built-in Botplay enabled or disabled. The button label reflects the current Botplay state so you always know what the action will do before you select it.
</ParamField>

## How Options in Pause Works

Selecting **Options** from the pause menu saves your current progress, plays the freaky menu music, and navigates to the full Options screen — the same one accessible from the main menu. Every setting is available, so you can make any adjustments you need without returning to song select.

<Warning>
  Exiting Options after entering it from the pause menu **restarts the song from the beginning** — any progress made in that run is lost. Make sure you are comfortable losing your current attempt before opening Options mid-song.
</Warning>

The song reloads automatically as soon as you leave the Options screen, meaning your changes take effect at the very start of the restarted run. There is no need to manually restart or navigate back to song select.

## How Botplay in Pause Works

When **Botplay in Pause** is enabled, the pause menu displays either **Enable Botplay** or **Disable Botplay** depending on whether Botplay is currently active. Selecting the entry immediately restarts the song from the beginning (timestamp 0) with Botplay toggled to the new state.

<Note>
  Practice Mode state is preserved when you toggle Botplay through the pause menu. If you had Practice Mode active before pausing, it remains active after the song restarts.
</Note>

<Tip>
  Enable both **Options in Pause Menu** and **Botplay in Pause** together for the fastest in-session adjustment workflow — change settings and toggle Botplay all without ever leaving the song selection screen.
</Tip>
