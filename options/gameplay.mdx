V-Extended's Gameplay options let you adjust how notes behave and how the play field looks. Open Options from the main menu (or the pause menu if you have that option enabled), then select **V-Extended** to find the settings below.

<Note>
  Options marked **PC only** do not appear in the mobile build of V-Extended. Options marked **Mobile only** do not appear in the PC build.
</Note>

<ParamField body="Ghost Tapping" type="checkbox" default="enabled">
  Prevents empty direction presses from counting as misses. When enabled, pressing an arrow with no note present does nothing — only hitting a note at the wrong time or missing one entirely registers as a miss. **PC only.**
</ParamField>

<ParamField body="Middlescroll" type="checkbox" default="disabled">
  Centers the player notes and splits the opponent notes between both sides of the screen. This gives your lane a larger, more prominent position in the middle of the play field. **PC only.**
</ParamField>

<ParamField body="Opponent Notes Opacity" type="number (0–100%, step 5)" default="100%">
  Changes the opacity of the opponent's receptors, notes, and sustain trails. Lower values fade the opponent lane out; setting it to 0% hides the opponent notes entirely.
</ParamField>

<Tip>
  Setting Opponent Notes Opacity to **0%** completely hides the opponent lane, letting you focus entirely on your own notes without visual distraction from the other side of the screen.
</Tip>

<ParamField body="Strumline Background" type="checkbox" default="disabled">
  Adds a gray lane background that sits above the game scene and below the HUD. This can help the note lanes stand out against busy or bright stage backgrounds.
</ParamField>

<ParamField body="Strumline BG Opacity" type="number (0–100%, step 5)" default="35%">
  Changes the opacity of the gray strumline background added by the Strumline Background option. Has no visible effect unless Strumline Background is enabled.
</ParamField>

<ParamField body="Strumline Background Padding" type="number (0–40 px, step 2)" default="14 px">
  Changes how far the lane backgrounds extend beyond the outermost arrows on each side. Increase this value to widen the background panels; set it to 0 to keep them flush with the note columns.
</ParamField>

<ParamField body="Alternative Note Input" type="checkbox" default="disabled">
  Uses the full screen as four touch lanes while keeping both strumlines in the desktop layout. Changes take effect on the next song load or restart. **Mobile only.**
</ParamField>
