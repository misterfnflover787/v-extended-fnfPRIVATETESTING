V-Extended Mobile (v1.2.1) delivers the same quality-of-life improvements that PC players enjoy — customizable HUD elements, score display tweaks, and pause menu enhancements — to Friday Night Funkin' V-Slice on mobile devices. On top of that, Mobile adds a touch-exclusive **Alternative Note Input** mode that turns the entire screen into four tap lanes, giving you a wider, more ergonomic target for every note.

## What's Different on Mobile

Most of V-Extended's options work identically on mobile and PC. A small set of features differ between the two platforms:

| | Mobile | PC |
|---|---|---|
| **Alternative Note Input** | ✅ Exclusive to Mobile | ❌ Not available |
| **Ghost Tapping** | ❌ Not available | ✅ Available |
| **Middlescroll** | ❌ Not available | ✅ Available |
| **Strumline Background Padding** | ❌ Not available | ✅ Available |
| All other options | ✅ Available | ✅ Available |

<Note>
  The three PC-only features — Ghost Tapping, Middlescroll, and Strumline Background Padding — will not appear in your options menu on mobile. This is expected behavior, not a missing feature.
</Note>

## Mobile Pause Menu

V-Extended Mobile uses an automatic layout for the pause menu that keeps every entry readable on any screen size. Entries are distributed evenly across the available space — spaced no more than 92 px apart — so nothing overlaps no matter how many items are present.

<Tip>
  If you enable both **Options in Pause Menu** and **Botplay in Pause** at the same time, the mobile pause menu will still fit all entries on screen without any items overlapping. You never need to choose between them.
</Tip>

This behavior is automatic and requires no configuration on your part. It kicks in any time the pause menu is opened during a song.
